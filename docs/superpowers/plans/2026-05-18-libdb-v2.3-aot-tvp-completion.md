# Lib.Db v2.3 AOT TVP Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete Lib.Db v2.3 as a single package with runtime TVP binding, AOT-safe fast paths, TVP schema drift handling, and repeatable SQL Server benchmarks.

**Architecture:** Keep the new runtime TVP API inside `Lib.Db` and remove the need for a separate `Lib.Db.TvpGen` package for normal users. The official AOT path is static-shape fluent mapping with `SqlDataRecord` streaming; reflection-based runtime mapping remains a JIT convenience path and is annotated as such. Schema drift support is handled through TVP fingerprints, targeted cache flush, and adaptive reader shape creation from cached DB schema metadata.

**Tech Stack:** .NET 10, C# 14, Microsoft.Data.SqlClient 7.0.1, SQL Server local `LIBDB_VERIFICATION_TEST`, xUnit, FluentAssertions, BenchmarkDotNet.

## Pre-Implementation Security Review Corrections

Codex Security plan review on 2026-05-18 found these blocking corrections. The plan below includes them before implementation starts:

- DB TVP schema metadata must feed the actual row reader and parameter binding path. Caching `TvpSchemaDescriptor` without a `LibDb.Tvp(descriptor, rows, ...)` path does not solve schema drift.
- Mixed scalar plus TVP parameters stay on the same fluent `.With(...)` path. Scalars bind from SP metadata; TVPs can be explicit descriptor values when schema drift handling is required.
- Public targeted flush must route through `ISchemaFlushCoordinator`, then into `ISchemaService`, so local and distributed invalidation semantics stay aligned.
- The Native AOT gate must execute a direct static-shape TVP bind path and fail on Lib.Db-owned AOT/trim warnings. DI and anonymous-object smoke alone is not sufficient evidence.
- BenchmarkDotNet artifacts are committed only after a secret-pattern scan of generated reports and logs.

```csharp
using System.Buffers;
using System.Data;
using System.Globalization;
using System.Linq;
using System.Security.Cryptography;
using System.Text;
using Lib.Db.Contracts.Models;

namespace Lib.Db.Execution.Tvp;

/// <summary>
/// Deterministic identity for a SQL Server TVP type shape.
/// </summary>
public readonly record struct TvpSchemaFingerprint(string Value)
{
    public static TvpSchemaFingerprint Create(TvpSchema schema)
    {
        ArgumentNullException.ThrowIfNull(schema);

        StringBuilder builder = new(128 + schema.Columns.Length * 96);
        Append(builder, schema.Name.ToUpperInvariant());
        Append(builder, schema.Columns.Length.ToString(CultureInfo.InvariantCulture));

        foreach (TvpColumnMetadata column in schema.Columns.OrderBy(static c => c.Ordinal))
        {
            Append(builder, column.Ordinal.ToString(CultureInfo.InvariantCulture));
            Append(builder, column.Name.ToUpperInvariant());
            Append(builder, ((int)column.SqlDbType).ToString(CultureInfo.InvariantCulture));
            Append(builder, column.MaxLength.ToString(CultureInfo.InvariantCulture));
            Append(builder, column.Precision.ToString(CultureInfo.InvariantCulture));
            Append(builder, column.Scale.ToString(CultureInfo.InvariantCulture));
            Append(builder, column.IsNullable ? "1" : "0");
            Append(builder, column.IsIdentity ? "1" : "0");
            Append(builder, column.IsComputed ? "1" : "0");
        }

        int byteCount = Encoding.UTF8.GetByteCount(builder.ToString());
        byte[]? rented = null;
        Span<byte> utf8 = byteCount <= 1024
            ? stackalloc byte[byteCount]
            : rented = ArrayPool<byte>.Shared.Rent(byteCount);

        try
        {
            int written = Encoding.UTF8.GetBytes(builder.ToString(), utf8);
            Span<byte> hash = stackalloc byte[32];
            SHA256.HashData(utf8[..written], hash);
            return new TvpSchemaFingerprint(Convert.ToHexString(hash));
        }
        finally
        {
            if (rented is not null)
                ArrayPool<byte>.Shared.Return(rented);
        }
    }

    public override string ToString() => Value;

    private static void Append(StringBuilder builder, string value)
    {
        builder
            .Append(value.Length.ToString(CultureInfo.InvariantCulture))
            .Append(':')
            .Append(value)
            .Append('|');
    }
}
```

```csharp
using Lib.Db.Contracts.Models;
using Lib.Db.Contracts.Schema;

namespace Lib.Db.Execution.Tvp;

public interface ITvpSchemaProvider
{
    Task<TvpSchemaDescriptor> GetAsync(
        TvpTypeName typeName,
        string instanceHash,
        CancellationToken ct);
}

public sealed record TvpSchemaDescriptor(
    TvpTypeName TypeName,
    long VersionToken,
    TvpColumnMetadata[] Columns,
    TvpSchemaFingerprint Fingerprint);

internal sealed class TvpSchemaProvider(ISchemaService schemaService) : ITvpSchemaProvider
{
    public async Task<TvpSchemaDescriptor> GetAsync(
        TvpTypeName typeName,
        string instanceHash,
        CancellationToken ct)
    {
        TvpSchema schema = await schemaService
            .GetTvpSchemaAsync(typeName.FullName, instanceHash, ct)
            .ConfigureAwait(false);

        return new TvpSchemaDescriptor(
            typeName,
            schema.VersionToken,
            schema.Columns,
            TvpSchemaFingerprint.Create(schema));
    }
}
```

```csharp
using System.Data;
using System.Collections.Concurrent;
using System.Linq;
using Lib.Db.Contracts.Models;

namespace Lib.Db.Execution.Tvp;

internal static class TvpRowAccessorCache
{
    private static readonly ConcurrentDictionary<Key, RuntimeTvpRowShape> s_cache = new();

    internal static RuntimeTvpRowShape GetOrAdd(
        Type rowType,
        TvpTypeName typeName,
        IReadOnlyList<TvpColumnMetadata> columns,
        TvpSchemaFingerprint fingerprint,
        TvpBindingPolicy policy)
    {
        Key key = new(rowType, typeName.FullName, fingerprint.Value, policy);
        return s_cache.GetOrAdd(key, static (cacheKey, state) =>
        {
            TvpColumnShape[] shapeColumns = state.Columns
                .OrderBy(static c => c.Ordinal)
                .Select(ToColumnShape)
                .ToArray();

            return RuntimeTvpDataReader.BuildShape(
                cacheKey.RowType,
                shapeColumns,
            cacheKey.Policy);
    }, (Columns: columns, TypeName: typeName));
    }

    internal static void Clear() => s_cache.Clear();

    internal static void ClearByTypeName(TvpTypeName typeName)
    {
        foreach (Key key in s_cache.Keys)
        {
            if (string.Equals(key.TypeName, typeName.FullName, StringComparison.OrdinalIgnoreCase))
                s_cache.TryRemove(key, out _);
        }
    }

    private static TvpColumnShape ToColumnShape(TvpColumnMetadata column)
        => new(
            column.Name,
            MapFieldType(column.SqlDbType),
            column.IsNullable,
            MapSize(column),
            column.Precision,
            column.Scale,
            column.SqlDbType);

    private static int MapSize(TvpColumnMetadata column)
    {
        if (column.MaxLength < 0)
            return -1;

        return column.SqlDbType is SqlDbType.NChar or SqlDbType.NVarChar or SqlDbType.NText
            ? checked((int)column.MaxLength / 2)
            : checked((int)column.MaxLength);
    }

    private static Type MapFieldType(SqlDbType dbType)
        => dbType switch
        {
            SqlDbType.BigInt => typeof(long),
            SqlDbType.Bit => typeof(bool),
            SqlDbType.Date or SqlDbType.DateTime or SqlDbType.DateTime2 or SqlDbType.SmallDateTime => typeof(DateTime),
            SqlDbType.DateTimeOffset => typeof(DateTimeOffset),
            SqlDbType.Decimal or SqlDbType.Money or SqlDbType.SmallMoney => typeof(decimal),
            SqlDbType.Float => typeof(double),
            SqlDbType.Int => typeof(int),
            SqlDbType.Real => typeof(float),
            SqlDbType.SmallInt => typeof(short),
            SqlDbType.Time => typeof(TimeSpan),
            SqlDbType.TinyInt => typeof(byte),
            SqlDbType.UniqueIdentifier => typeof(Guid),
            SqlDbType.Binary or SqlDbType.Image or SqlDbType.Timestamp or SqlDbType.VarBinary => typeof(byte[]),
            _ => typeof(string)
        };

    private readonly record struct Key(
        Type RowType,
        string TypeName,
        string Fingerprint,
        TvpBindingPolicy Policy);
}
```

```csharp
static async Task EnsureSchemaAsync(string connectionString, CancellationToken ct)
{
    await using SqlConnection connection = new(connectionString);
    await connection.OpenAsync(ct);

    string sql = """
        IF TYPE_ID(N'dbo.libdb_aot_OrderItem') IS NULL
            EXEC(N'CREATE TYPE dbo.libdb_aot_OrderItem AS TABLE
            (
                Id int NOT NULL,
                Sku nvarchar(64) NOT NULL,
                Qty int NOT NULL
            )');

        EXEC(N'
        CREATE OR ALTER PROCEDURE dbo.libdb_aot_InsertOrderItems
            @OrderId int,
            @RequestedBy nvarchar(64),
            @Rows dbo.libdb_aot_OrderItem READONLY
        AS
        BEGIN
            SET NOCOUNT ON;
            SELECT SUM(Qty) FROM @Rows;
        END');

    string connectionString,

    AotSmokeRow[] rows,
    CancellationToken ct)
{

    await using SqlCommand command = new("dbo.libdb_aot_InsertOrderItems", connection)

        CommandType = CommandType.StoredProcedure
```

```markdown
# Lib.Db v2.3 AOT TVP Risk Ledger

## Reviewed On

2026-05-18

## Risks

| Area | Risk | Control |
| --- | --- | --- |
| TVP type name | Identifier injection through user-provided type name | `TvpTypeName.Parse` accepts two-part identifiers only and rejects unsafe characters. |
| Raw SQL | Value injection through interpolated SQL | Public docs prefer `Sql(FormattableString)` or `.With(...)`; raw SQL policy remains enforced. |
| Connection strings | Secret exposure in logs and docs | Logs use `DbDiagnosticRedactor`; docs and reports list only environment variable names. |
| Benchmark artifacts | BenchmarkDotNet reports can capture command-line or environment context | Artifact scan prints only matching paths and blocks commit on connection-string patterns. |
| Local benchmark encryption | `Encrypt=False` may be used for controlled local SQL Server benchmarking | Benchmark docs mark it local-only; production connection security policy remains unchanged. |
| AOT reflection fallback | Reflection and expression compilation are not Native AOT-safe | Static-shape `.Column(...)` path is the official AOT path; reflection path is annotated. |
| Schema drift | DB TVP changes can invalidate row shape caches | Fingerprint-aware cache and `FlushTvpAsync` clear stale TVP shape entries. |
| Schema metadata visibility | Catalog views expose only metadata visible to the caller | Docs require the app login to have explicit metadata visibility through normal SQL permissions; failures are diagnostic, not silent fallback. |
| Distributed flush | Local-only TVP invalidation leaves other processes stale | Public `FlushTvpAsync` routes through `ISchemaFlushCoordinator` before local cache cleanup. |
| Permissions | TVP execution requires SQL permissions | Docs list `EXECUTE` and `REFERENCES` permission requirement for TVP type usage. |
```
