# Lib.Db v2.3 Runtime TVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `Lib.Db.TvpGen` with a runtime-first TVP pipeline in `Lib.Db`, add a fluent-compatible mixed-parameter API, and benchmark it against the previous generated-accessor approach with a real SQL Server database.

**Architecture:** TVP support becomes a runtime binding layer inside `Lib.Db`. Explicit `LibDb.Tvp(...)` values and registered `IEnumerable<T>` mappings flow through the existing parameter binder, which creates `SqlParameter` values with `SqlDbType.Structured`, validated `TypeName`, schema-aware streaming readers, and strict/adaptive schema policies. The old generator project is removed from production packaging, while benchmark-only generated-style baseline code remains in `Benchmarks/Lib.Db.Benchmarks`.

**Tech Stack:** .NET 10, C# preview, Microsoft.Data.SqlClient, SQL Server local/direct TCP connection, xUnit v3, BenchmarkDotNet.

```csharp
namespace Lib.Db.Execution.Tvp;

internal readonly record struct TvpTypeName(string Schema, string Name)
{
    public string FullName => $"{Schema}.{Name}";

    public static TvpTypeName Parse(string? value)
    {
        if (string.IsNullOrWhiteSpace(value))
            throw new ArgumentException("Invalid TVP type name.", nameof(value));

        string normalized = value.Trim().Replace("[", string.Empty).Replace("]", string.Empty);
        string[] parts = normalized.Split('.', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);

        string schema;
        string name;

        if (parts.Length == 1)
        {
            schema = "dbo";
            name = parts[0];
        }
        else if (parts.Length == 2)
        {
            schema = parts[0];
            name = parts[1];
        }
        else
        {
            throw new ArgumentException("Invalid TVP type name.", nameof(value));
        }

        if (!IsSafeIdentifier(schema) || !IsSafeIdentifier(name))
            throw new ArgumentException("Invalid TVP type name.", nameof(value));

        return new TvpTypeName(schema, name);
    }

    private static bool IsSafeIdentifier(string value)
    {
        if (value.Length == 0 || value.Length > 128)
            return false;

        char first = value[0];
        if (!(char.IsLetter(first) || first == '_' || first == '@' || first == '#'))
            return false;

        for (int i = 1; i < value.Length; i++)
        {
            char ch = value[i];
            if (!(char.IsLetterOrDigit(ch) || ch == '_' || ch == '@' || ch == '#'))
                return false;
        }

        return true;
    }
}
```

```csharp
namespace Lib.Db.Execution.Tvp;

public sealed class TvpOptions
{
    internal TvpMappingRegistry Registry { get; } = new();

    public bool EnableAutoTvpBinding { get; set; } = true;

    public TvpOptions Map<T>(
        string typeName,
        TvpBindingPolicy policy = TvpBindingPolicy.Strict)
    {
        Registry.Map<T>(typeName, policy);
        return this;
    }
}
```

```csharp
using System.Collections.Concurrent;

namespace Lib.Db.Execution.Tvp;

public sealed class TvpMappingRegistry
{
    private readonly ConcurrentDictionary<Type, (TvpTypeName TypeName, TvpBindingPolicy Policy)> _mappings = new();

    public void Map<T>(string typeName, TvpBindingPolicy policy = TvpBindingPolicy.Strict)
        => _mappings[typeof(T)] = (TvpTypeName.Parse(typeName), policy);

    public bool TryResolve(Type rowType, out TvpTypeName typeName, out TvpBindingPolicy policy)
    {
        if (_mappings.TryGetValue(rowType, out var entry))
        {
            typeName = entry.TypeName;
            policy = entry.Policy;
            return true;
        }

        typeName = default;
        policy = TvpBindingPolicy.Strict;
        return false;
    }
}
```
